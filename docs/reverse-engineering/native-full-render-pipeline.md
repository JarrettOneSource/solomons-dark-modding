# Native full render pipeline

## Scope, identity, and closure claim

This report owns the complete retail frame-to-pixel pipeline, not one scene.
Its boundary begins at the application frame dispatcher, includes every shared
Graphics primitive and state transition, every Direct3D 9 device call, every
registered CPU-surface/world render root, every class/vtable renderer that
reaches those seams, and ends at `IDirect3DDevice9::Present`. Scene-specific
animation and actor behavior remain in their system reports; this report owns
how their submitted vertices, textures, colors, state, and targets become a
frame.

- Binary: retail `SolomonDark.exe` 0.72.5, 4,723,200 bytes, SHA-256
  `03a834566ce70fd8088f4cf9ee6693157130d8aec28c092cb814d6221231f1e3`.
- Preferred image base: `0x00400000`.
- Static source: canonical Ghidra 12.0.3 project through the repository's
  read-only replica wrapper.
- Graphics is an embedded `MyApp` subobject at `MyApp+0x1D0`; addresses such
  as Graphics `+0x221` and application-global `+0x3F1` name the same byte.
  This distinction is required when auditing instructions.

as
[`native-full-render-pipeline-xrefs.json`](native-full-render-pipeline-xrefs.json).

menus, dialogs, Create, fixed Regions, Arena, HUD surfaces, editor, and
portrait capture all enter through the same registered-object frame and shared
Graphics state. Arena actors add their own queue, but that queue still invokes
the same concrete `+0x0C` renderers and primitives.

## Direct3D ownership and bypass proof

The D3D9 device global `0x00B401E8` has 129 direct references in 44
functions. Every containing function belongs to App/device lifecycle, the
shared Graphics core, texture/surface helpers, shader setup, or ExactText's
temporary sampling state. No menu, world, actor, projectile, spell, weather,
or effect class calls a raw device draw method.

The nine former non-function references at `0x00440BAB..0x00440D06` are the
jump-table bodies of `D3D_SetTransformProgram 0x00440BA0`, not hidden scene
draws. Raw instructions show `SetTransform` for view/world/texture transforms
and their enable/disable texture-stage transitions. All scene geometry enters
the buffered `Vertex2D` lane and reaches only:

- `DrawPrimitiveUP` at Graphics flush for non-indexed triangles; or
- `DrawIndexedPrimitiveUP` at Graphics flush for indexed triangles.

Texture creation, render-target copy/readback, screenshot capture, reset, and
Present are device operations but not alternate painter lanes.

## Fixed-function baseline

`D3D_ResetFixedFunctionState 0x0043FB60` installs the frame baseline:

- FVF `0x142` (`XYZ | DIFFUSE | TEX1`);
- depth disabled, lighting disabled, alpha blending enabled, Gouraud shading,
  clipping/color-vertex processing enabled, and culling disabled by the
  Graphics frame reset;
- stage-zero texture/color modulation for ordinary textured work;
- linear minification and magnification at the stock 1:1 target ratio;
- texture address wrap on U/V after Graphics reset; and
- no vertex shader and no post-frame shader.

Graphics state is requested, cached, and dispatched only after buffered
vertices are flushed. A state change therefore never mutates vertices already
submitted to the batch.

### Blend selectors

Graphics `+0x221` selects exactly:

| Selector | Source | Destination | Operation |
| ---: | --- | --- | --- |
| `0` | `SRCALPHA` | `INVSRCALPHA` | ordinary source-over |
| `1` | `SRCALPHA` | `ONE` | additive |
| `2` | `ZERO` | `SRCCOLOR` | destination multiplied by source RGB |

Direct3D separate-alpha blending remains disabled. Reset
`D3D_ResetFixedFunctionState 0x0043FB60` sets the ordinary blend states but
never writes render state `206` (`D3DRS_SEPARATEALPHABLENDENABLE`), and a
whole-image scalar census finds no renderer-side `206` write. The selector's
source/destination factors therefore apply to alpha as well as RGB: normal
alpha is `srcA*srcA + dstA*(1-srcA)`, additive alpha is
`srcA*srcA + dstA`, and multiply alpha is `dstA*srcA`. This is observable
inside transparent Storm/Leviathan render targets even though final backbuffer
alpha is not presented.

The instruction census contains 150 literal additive writes, 14 literal
multiply writes, 147 literal normal writes, and 43 register-sourced exact
selector writes. Register-sourced writes are not unknown state: their exact
instructions, source registers, classes, vtable slots, and neighboring literal
restores are retained in the membership catalog.

### Texture color and address selectors

Graphics `+0x223` selects fixed-function textured modulation (`0`) or
untextured diffuse vertex color (`1`). The census contains 21 literal textured
and 27 literal untextured writes plus exact register-sourced restores. Graphics
`+0x239` selects clamp (`0`) or wrap (`1`); the frame baseline is wrap.
`native-asset-system.md`'s complete displacement census finds no retail
request override after reset: stock page sampling remains wrap for the whole
frame. Clamp is a compiled dispatcher alternative, not an active stock branch.
`Graphics_SetFilter 0x00421560` has 78 exact references from 34 callers and
switches min/mag together between point and linear after flushing. Those
paired callers bracket ExactText/font glyph submission and restore the prior
filter afterward; ordinary sprite, VFX, atlas, and render-target work retains
the frame's linear filter.

## Pixel shaders

The executable contains exactly two game-authored `ps_2_0` sources, both
compiled by `0x0043FD80`. No game-authored vertex shader source is present.

### Arena saturation

The saturation object at `0x00B401F4` is selected only by the two
`Arena::Render` request writes at `0x0046ECA9` and `0x00470A6A`. The first
requests `0.65`; the second restores `1.0`, which dispatches
`SetPixelShader(NULL)`. No other scene writes the saturation request.

Its exact pixel equation remains:

```text
textureGrey = avg(texture.rgb)
vertexGrey  = avg(vertex.rgb)
real        = texture.rgb * vertex.rgb
out.rgb     = lerp(textureGrey * vertexGrey, real, 0.65)
out.a       = texture.a * vertex.a
```

Arena nested render targets inherit this shader until the final restore.
Menus, fixed Regions, Hub/HUD surfaces after Arena, editor, loader, and portrait
capture do not.

### Dormant blur capability

The blur object at `0x00B401F8` has only two xrefs: compilation and
`D3D_SelectBlurShader 0x00442AF0`. That helper has one caller, the central state
dispatcher. Graphics constructs both blur request/effective fields as zero,
and the complete state-write census finds no retail writer. The blur request
remains constructor-zero and has no retail writer. The blur shader is
therefore compiled but unreachable in shipped rendering.

The earlier Arena report's “20-sample cross” description was imprecise. The
source loops `aU=-3..2`, adds four samples per iteration, and divides the 24
accumulated samples by 20. If a mod deliberately writes the dormant request,
the result is a dormant 1.2-gain cross blur; stock does not select it. A web parity
renderer must not invent blur/glow merely because this compiled capability
exists.

## Texture, target, and alpha contract

All stock page and loose-image decode paths produce unpremultiplied BGRA.
Mode-zero upload uses A8R8G8B8 without premultiplying RGB. Sprite records keep
their original page UVs. Render textures are explicit texture records selected
by `Graphics_BeginRenderToTexture 0x004214C0` and restored by
`Graphics_EndRenderToTexture 0x00421430`; the same state dispatcher, transforms,
and primitive batches operate inside them.

Premultiplied and unpremultiplied representations are algebraically
interchangeable for ordinary/additive blending only when the shader and blend
factors agree. They are not interchangeable for native selector `2`, whose
`ZERO/SRCCOLOR` equation consumes source RGB independently of source alpha.
Web multiply paths must therefore preserve/unpremultiply stock RGB.

## Camera feedback residual

The scene report's zero-shake caveat is superseded by the complete camera
investigation. Arena `0x0046F100..0x0046F276` applies a uniform
`1 + magnitude` scale around the local Player's projected point. It is a
deterministic player-anchored pulse, not random XY displacement. Construction,
impulse writers, accumulation, damping, settings gate, and all enemy/secondary
members are closed in

## Web-port consequences

The full native graph predicts these shared requirements:

1. apply the `0.65` pixel shader only to the Arena interval, including nested
   Arena targets, never to complete canvases or fixed/menu/HUD scenes;
2. preserve raw texture RGB through multiply paths and custom shaders;
3. use the exact normal/additive/multiply RGB and alpha factors per renderer
   member, including nested transparent targets;
4. retain genuine vertex colors for all quad/line orientations;
5. use wrap addressing throughout stock rendering and default to linear
   filtering, with point filtering only at cataloged temporary text branches;
6. model render targets as nested passes with inherited state, not flattened
   precolored images;
7. do not add stock blur, bloom, CSS brightness, or color-matrix approximations
   without a native selector; and
8. preserve the registered surface/world/HUD painter sequence across scene
   transitions and teardown.

WebGL2 can represent every active retail mechanism in this boundary. There is
no `blocked-by-platform` member and no remaining extractable native unknown in
the render pipeline itself. Visual parity still requires auditing each Website
consumer against this catalog and browser comparison; that implementation
receipt belongs in the Website parity ledger.
