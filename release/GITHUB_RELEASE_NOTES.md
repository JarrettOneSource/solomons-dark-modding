# Solomon Dark Multiplayer Beta v0.1.0-beta.29

- Connection progress now stays in the launcher's bottom status area throughout Host, Join, and Launch.
- Delegated player control now fires the equipped primary attack through the native gameplay path, and pressing F9 fully restores movement, input, casting, targets, and the selected primary.
- Multiplayer level-ups now wait until every player chooses, show who is still waiting, and apply each selection to the correct wizard.
- Dead players now respawn reliably when wave boundaries overlap, without losing their equipped primary.
- Everyone picks a loadout before each match with the previous choice preselected; host-first and client-first arrivals remain synchronized, and the lobby directory shows Picking Loadout until launch.
- Scripted movement now replaces earlier movement requests instead of stacking speed.
- Duplicate ally health-bar rows no longer appear.
- Enemy deaths no longer play on clients before host confirmation, and remote participants keep their proper lighting.
- The release contains no bundled mods or generated runtime residue.

Download the ZIP. Extract the ZIP. Start `SolomonDarkMultiplayerBeta.exe`.
