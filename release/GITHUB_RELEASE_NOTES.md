# Solomon Dark Multiplayer Beta v0.1.0-beta.16

- Fresh Solo, Host, and Join saves now go straight into normal gameplay. Enable **Show stock tutorial** in launcher Settings if you want to play the original tutorial.
- The stock level-up picker no longer has a black diagnostic texture labeled "Choose your skill upgrade" drawn over it.
- Client-owned players now reach native death correctly during organic multiplayer combat instead of sometimes remaining alive at terminal health.
- Other players now see host-owned deaths at the correct native -10 HP boundary instead of roughly 1.1-1.3 seconds early.
- Normal player launches keep all game audio enabled. **Disable all audio** in launcher Settings now provides an optional silent launch, while repo automation remains silent by default.
- The release contains no bundled mods or generated runtime residue.

Download the ZIP. Extract the ZIP. Start `SolomonDarkMultiplayerBeta.exe`.
