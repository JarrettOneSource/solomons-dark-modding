# Solomon Dark Multiplayer Beta v0.1.0-beta.14

- Protocol 84 improves multiplayer enemy synchronization and makes remote spell casts start and stop at the correct time.
- A dead host can keep spectating while living players finish the wave; the death grace clear happens once without repeated staff-drop effects.
- Solo deaths and multiplayer sessions with no living players now reach the stock Game Over screen.
- Dead players can still choose level-up skills, then respawn for the next round with matching loadouts and progression.
- Joining a lobby now waits for the player to click Launch Game before entering the loadout flow.
- Launcher updates now show live download and installation progress before restarting into the new version.
- The release contains no bundled mods or generated runtime residue.

Download the ZIP. Extract the ZIP. Start `SolomonDarkMultiplayerBeta.exe`.
