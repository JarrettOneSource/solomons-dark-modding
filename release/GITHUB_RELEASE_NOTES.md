# Solomon Dark Multiplayer Beta v0.1.0-beta.15

- Seeded Boneyard decorations, including trees and compact decorations, now generate identically for every player.
- Enemy movement again uses a fixed 150 ms interpolation delay, with fidelity checks covering teleports, rubber-banding, freezes, and lingering ghost enemies.
- Players now respawn at the Boneyard spawn point, and their old corpses are cleaned up for everyone.
- Air damage was rechecked against the current multiplayer build and continues to work correctly.
- The release contains no bundled mods or generated runtime residue.

Download the ZIP. Extract the ZIP. Start `SolomonDarkMultiplayerBeta.exe`.
